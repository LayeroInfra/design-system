# design-system — примитивы и токены

React + TypeScript + Tailwind. Витрина — Storybook. Отсюда примитивы
разъезжаются в `frontend/control-plane` командой `npm run sync:ds`.
Правила репозитория — `AGENTS.md`.

## Модель распространения — копирование, не пакет

Примитивы не ставятся зависимостью, а **синхронизируются** в панель.
Следствия, о которых надо помнить:

* ломающая правка примитива **не проявится здесь** — она проявится в панели;
* синхронизацию гоняет `sync-design-system.yml`, а он **сломан** (снесённые
  раннеры, тикет `T-20260816-6`): прогон от 16.08 висел в очереди 8,6 часа.
  Значит правка может не доехать, и узнать об этом можно только глазами;
* пока так — менял публичный проп, прогони `make -C ../frontend check`
  в том же заходе.

## Правила, из которых здесь всё

1. **Токен, а не литерал.** Цвет, отступ, радиус, тень, типографика задаются
   токеном. Литеральное значение в компоненте — дефект, даже если выглядит
   верно.
2. **Обе темы держит токен, а не ветвление.** Компонент не должен знать,
   светлая тема или тёмная.
3. **Публичный проп не меняется в одиночку.** Только вместе с правкой
   потребителей в панели.
4. **Внешних шрифтов и иконок по сети нет.** Только самохост.
5. **Доступность обязательна:** контраст WCAG AA, фокус виден с клавиатуры,
   у интерактивных элементов есть доступное имя.
6. **У компонента есть story на каждое состояние** — включая пустое и
   состояние ошибки. Сборка витрины и есть единственное, что реально
   исполняет каждый компонент.

## Проверка

```bash
make check       # типы + сборка Storybook, ~12 с
make typecheck   # tsc --noEmit
make storybook   # витрина локально
```

Сборка витрины входит в `check` намеренно: тайпчек ловит форму, сборка —
способность компонента вообще отрендериться.

🚨 **Тестов нет ни одного, линтера нет, визуальной регрессии нет** — story
есть, снимков для сравнения нет. Тикет `T-20260816-14`.

## Чего дизайн-система НЕ делает

Не знает про API и данные, не содержит страниц и маршрутов, не решает
продуктовых вопросов — только форма и поведение примитива.
