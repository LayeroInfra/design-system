# AGENTS.md — design-system

Компоненты и токены Layero. React + TypeScript + Tailwind, витрина — Storybook.
Отсюда примитивы разъезжаются в `frontend/control-plane` (`npm run sync:ds`).

Сначала прочитай корневой `../AGENTS.md` — необратимые запреты и доступы.

---

## Команды

```bash
make check       # ⬅ типы + сборка витрины. ~12 с
make typecheck   # tsc --noEmit
make build       # сборка Storybook
make storybook   # витрина локально
make setup       # npm ci
```

Сборка витрины входит в `check` намеренно: она единственная, кто реально
исполняет каждый компонент. Тайпчек ловит форму, сборка — способность
компонента вообще отрендериться.

**Чего `check` НЕ покрывает:** тестов нет ни одного, линтера нет
(тикет `T-20260816-14`); визуальной регрессии нет — story есть, снимков
для сравнения нет. Ломающая правка примитива проявится не здесь, а в
панели: менял публичный проп — прогони `make -C ../frontend check`.

---

## Definition of Done

- **`make check` зелёный**;
- компонент виден в Storybook и имеет story на каждое состояние,
  включая пустое и состояние ошибки;
- проверен в светлой и тёмной теме;
- потребители не сломаны: если менял примитив — прогнал сборку
  `frontend/control-plane`;
- закоммичено и запушено.

## Жёсткие ограничения

1. **MUST** — цвет, отступ, радиус, тень, типографика задаются токеном.
   Литеральное значение в компоненте — дефект, даже если выглядит верно.
2. **MUST** — компонент работает в обеих темах. Тема переключается токенами,
   а не ветвлением в компоненте.
3. **MUST NOT** — менять публичный проп существующего компонента без правки
   потребителей в `frontend/control-plane` в том же заходе. Ломающее
   изменение примитива не проявится здесь — оно проявится в панели.
4. **MUST NOT** — тянуть внешние шрифты и иконки по сети. Только самохост.
5. **MUST** — доступность: контраст WCAG AA, фокус виден с клавиатуры,
   у интерактивных элементов есть доступное имя.
